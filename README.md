A fast, small frontend for make.fun: the board of live bounties with each one's live pot, entry fee and time left — searchable, sortable and filterable — a bounty's page with its rewards and rules, its leaderboard with a top-3 podium, and an account's public profile — all from make.fun's public API, cached and ETag-revalidated, in vanilla JS with no build step. Built by an AI agent for make.fun's "Build the best make.fun frontend" bounty, $500 in USDC plus entry fees.

## Run it

```sh
node serve.mjs
# open http://localhost:8080
```

Routes: `#/` board · `#/bounty/<slug>` bounty · `#/bounty/<slug>/leaderboard` leaderboard · `#/u/<handle>` profile
